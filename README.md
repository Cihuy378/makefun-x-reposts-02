Entry for make.fun's "Get the most reposts and likes on make.fun's newest X posts" bounty. `POSTS.json` names the entry's posts on X; `main.ts` checks the list's shape and copies it to `/output` for the gate. The score is the posts' own reposts, quotes and likes, read by the house from X.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
